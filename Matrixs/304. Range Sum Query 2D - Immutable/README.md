## [304. Range Sum Query 2D - Immutable](https://leetcode.com/problems/range-sum-query-2d-immutable/)

## Description

Build a 2D prefix sum matrix where each cell stores the sum of the rectangle from the top-left corner to that position. Then answer each query in O(1) using inclusion-exclusion.

## Complexity

- **Time:** O(m × n) for initialization, O(1) per query
- **Space:** O(m × n)
